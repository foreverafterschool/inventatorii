Intră în panou

Cum obțin cheia? (o singură dată pe acest dispozitiv)
  1. Intră pe GitHub cu contul foreverafterschool și deschide pagina pentru chei noi.
  2. Dă-i un nume (de ex. „Panou admin”) și alege data de expirare.
  3. La Repository access alege Only select repositories și bifează escaperoom, neuraisland și inventatorii.
  4. La Permissions → Repository permissions → Contents alege Read and write.
  5. Apasă Generate token, copiază cheia și lipește-o mai sus.
Cheia rămâne salvată doar în acest browser și merge la panourile tuturor celor trei jocuri. Nu o trimite nimănui: cu ea se pot modifica jocurile.
